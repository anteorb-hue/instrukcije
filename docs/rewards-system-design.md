# 🎁 Sustav Nagrađivanja i Bodovanja - Instrukcije.hr

## 📋 Pregled Sustava

Sustav nagrađivanja osmišljen je da motivira korisnike (instruktore i učenike) da ostanu aktivni na platformi i ne prelaze na direktne dogovore izvan aplikacije.

## 🔗 Referral Program

### Kako Funkcionira

1. **Pozivač dobije unique referral link**
2. **Novi korisnik se registrira preko linka**
3. **Obje strane dobiju nagrade:**

#### Kad Učenik Pozove Učenika:
- **Pozivač**: 50 bodova + 10 EUR credit nakon prve instrukcije pozvanog
- **Pozvani**: 10 EUR discount na prvu instrukciju

#### Kad Instruktor Pozove Instruktora:
- **Pozivač**: 100 bodova + 5% od zarade pozvanog prvih 3 mjeseca
- **Pozvani**: Besplatni premium profil prvi mjesec

#### Kad Učenik Pozove Instruktora (ili obrnuto):
- **Pozivač**: 75 bodova + 15 EUR credit
- **Pozvani**: Onboarding support + featured status prvih 7 dana

## 🎯 Kako Sustav Sprečava Odlazak S Platforme

### 1. **Gamifikacija**
- Vizualni prikaz napretka (progress bars)
- Rangovi i bedževi
- Leaderboard (top instruktori/učenici mjeseca)

### 2. **Financijska Motivacija**
- Direktni popusti i voucheri
- Smanjene provizije za instruktore
- Besplatne instrukcije za lojalne učenike

### 3. **Ekskluzivni Benefiti**
- VIP support za top korisnike
- Prioritet u bookingu
- Featured status = više vidljivosti = više zarade

### 4. **Penali Za Kršenje Pravila**
- Gubitak bodova za dogovore izvan platforme
- Suspenzija ili ban
- Gubitak ranga i benefita

### 5. **Transparentnost**
- Jasno prikazani bodovi na profilu
- Historia bodova (earned/spent)
- Notifikacije za nova postignuća

## 📝 Tehnički Zahtjevi

### Database Schema

```typescript
interface UserPoints {
  userId: string
  totalPoints: number
  currentTier: 'BRONZE' | 'SILVER' | 'GOLD' | 'PLATINUM' | 'ELITE'
  pointsHistory: PointTransaction[]
  referralCode: string
  referredBy?: string
  rewards: UserReward[]
}

interface PointTransaction {
  id: string
  points: number
  type: 'EARNED' | 'SPENT' | 'PENALTY'
  reason: string
  relatedBookingId?: string
  createdAt: Date
}

interface UserReward {
  id: string
  type: 'DISCOUNT' | 'VOUCHER' | 'FEATURED' | 'FREE_LESSON'
  value: number
  expiresAt: Date
  used: boolean
}
```

## 💡 Best Practices

1. **Transparentnost**: Uvijek objasni zašto su bodovi dodani/oduzeti
2. **Fairness**: Sustav mora biti pošten za sve
3. **Engagement**: Redovite promocije i special events
4. **Balance**: Ne pretjerivati sa bodovima (inflacija)
5. **Monitoring**: Pratiti abuse i fraud
